# Changelog

## 1.1.1 - 2026-10-21

### Added

- 网络代理支持：自动读取系统代理，也可手动填写；GitHub Raw / jsDelivr 镜像回退与失败重试
- 订阅导入支持勾选音源、实时进度、失败清单与重试
- 音源加载支持顶层 `const/let/class env`（以及 `module`、`process`、`console`）声明
- 播放模式合并为单一按钮，依次切换：顺序播放 / 列表循环 / 单曲循环 / 随机播放

### Fixed

- 修复随机播放与单曲循环同时开启时，随机播放不生效的问题
- 修复安装音源时 `userVariables` 声明被覆盖、配置保存后失效的问题
- 修复订阅导入因 `ECONNRESET` 失败且缺少明确提示的问题
- 改进 HTTP 423 / 404 / 403 / 429 与音源语法错误的提示文案

## 1.1.0 - 2026-10-19

### Added

- 歌曲 / 专辑 / 歌手 / 歌单 四种类型的聚合搜索，结果按音源分栏展示
- 专辑、歌单、歌手、排行榜详情页，支持分页加载与播放全部
- 排行榜浏览：按音源分组展示榜单并查看榜单详情
- 导入单曲 / 歌单：解析链接或 ID，支持播放、加入列表与批量收藏
- 离线下载：音质自动回退、实时进度、下载任务管理与打开所在文件夹
- 桌面歌词：独立置顶窗口，可拖动、可调字号，实时同步歌词与翻译
- 全新品牌图标，与界面左上角视觉保持一致

### Changed

- 数据存储迁移至 ZTools 数据库，支持官方数据同步，不再写入本地文件
- 左侧菜单与顶部品牌区重新设计，适配矮窗口且不再与播放条重叠
- 底部播放条在矮窗口下更紧凑，时间为横向布局
- 搜索、音源管理、播放器等页面的局部样式与交互优化

### Fixed

- 修复音质标签在窄容器中竖排显示的问题
- 修复侧栏底部「添加音源」与播放条重叠的问题
- 修复桌面歌词在 `file://` 窗口下跨域通信不稳定的问题

## 1.0.0 - 2026-10-17

### Added

- 首个版本：兼容 MusicFree 协议的音源加载与运行时
- 多源聚合搜索、在线播放、逐行歌词、播放队列、收藏与最近播放
- 音源管理：链接 / 订阅 / 本地文件 / 粘贴代码导入，支持启停、更新、卸载与参数配置
